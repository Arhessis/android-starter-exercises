# Android Basics with Compose - Starter Exercises

A collection of introductory Android applications built using Kotlin and Jetpack Compose as part of Google's [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) curriculum.

## 📱 Projects Included

* **Cartedeprsentation (Business Card App)**: A single-screen profile card practicing basic Compose UI elements (`Text`, `Image`, `Column`, `Row`, and Material 3 theming).
* **DiceRoller**: An interactive dice-rolling app demonstrating mutable state management (`remember`, `mutableStateOf`) and handling user click interactions.
* **Happybirthday**: A foundational layout project exploring Compose composables, positioning, and resource management.

## 🛠️ Tech Stack & Skills
* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose (Material 3)
* **IDE:** Android Studio
* **Core Concepts:** State management, layout composables, modifier chains, and resource imports.
